# Images for Conciergerie Website

Please upload the following images to this directory:

## Logo
**logo.png** - Your company logo
- Format: PNG (with transparent background recommended)
- Recommended size: 200x200 pixels or larger (square)
- Used in: Header and Footer

## Hero Images for Homepage

Please upload 4 images with the following names:

1. **hero-1.jpg** - A luxury property interior (living room, modern apartment, etc.)
2. **hero-2.jpg** - Guest check-in experience (keys, welcome setup, entrance, etc.)
3. **hero-3.jpg** - Professional cleaning service (clean bedroom, fresh linens, etc.)
4. **hero-4.jpg** - Revenue/analytics theme (charts, money, growth visualization, etc.)

## Image Requirements:
- Format: JPG or PNG
- Recommended size: 800x600 pixels or higher
- Aspect ratio: 4:3 works best for hero images
- File size: Keep under 500KB for optimal performance

## Current Usage:
- **Logo**: Displayed in the header (with gradient background) and footer
- **Hero images**: Displayed in an animated 2x2 grid on the homepage hero section with floating animations
