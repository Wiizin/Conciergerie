# Hero background video

Add your hero background video here so it plays behind the homepage hero section.

- **Filename:** `hero-bg.mp4`
- **Recommended:** Modern interior, property, or lifestyle footage; loop-friendly, not too busy.
- **Format:** MP4 (H.264) for best browser support.
- **Length:** 10–30 seconds (it will loop).
- **Size:** Prefer under ~5 MB for fast loading.

If `hero-bg.mp4` is missing, the hero still displays with a dark overlay and neutral background.
